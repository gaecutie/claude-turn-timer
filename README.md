# turn-timer

Shows "Working for Xm Ys" above the prompt while Claude works, then "Worked for Xm Ys" once it is done, so you can see at a glance when Claude has finished. It also shows your Codex CLI usage limits (5-hour and weekly percentages) read from ~/.codex/sessions.

## Install

```
/plugin install turn-timer --marketplace gaecutie/claude-turn-timer
```
